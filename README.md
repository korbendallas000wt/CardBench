# CardBench

Веб-приложение для работы с коллекционными карточками.

## Возможности

- Редактирование карточек
- Просмотр галереи
- Импорт/экспорт данных
- Печать карточек

## Технологии

- React 18
- TypeScript
- Vite
- Tailwind CSS

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

Проект автоматически деплоится на GitHub Pages при пуше в ветку `main`.

Страница проекта: https://korbendallas000wt.github.io/CardBench/

## 🛠 Правила разработки и версионирования (для AI и разработчиков)

1. **Версионирование**: Обновление версии в `package.json` и добавление записи в `src/changelog.ts` (и `CHANGELOG.md`) выполняется **вручную** при подготовке логического релиза.
2. **Формат коммитов**: Используйте Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
3. **Деплой**: Автоматический при пуше в ветку `main` через GitHub Actions (workflow `.github/workflows/deploy.yml`).
4. **История изменений в UI**: При добавлении новых фич или исправлений **всегда** обновляйте массив `changelog` в `src/changelog.ts`, чтобы модальное окно "История версий" в интерфейсе оставалось актуальным.
