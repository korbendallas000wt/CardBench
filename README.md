# CardBench

Веб-приложение для работы с коллекционными карточками.

## Возможности

- Редактирование карточек
- Просмотр галереи
- Импорт/экспорт данных
- Печать карточек

## Технологии

- React 18
- TypeScript
- Vite
- Tailwind CSS

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

Проект автоматически деплоится на GitHub Pages при пуше в ветку `main`.

Страница проекта: https://korbendallas000wt.github.io/CardBench/
