# Changelog

Все значимые изменения проекта будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] - 2026-10-20

### Добавлено
- Система атрибутов-слоёв с точным позиционированием (текст и изображения).
- Ползунки для управления позицией X/Y, размером, поворотом и скруглением элементов.
- Поддержка наложения элементов друг на друга в любом порядке.

### Изменено
- Переименование приложения из Card Forge в Card Bench.

## [1.1.1] - 2026-10-20

### Изменено
- Переименование приложения из Card Forge в Card Bench для соответствия названию проекта.

## [1.1.0] - 2026-10-20

### Добавлено
- Интеграция ИИ-генерации изображений через Pollinations.ai прямо в редакторе карточек.
- Панель генерации с быстрыми тегами и конвертацией результата в base64 (карточка остаётся полностью автономной).
- Успешное тестирование и подтверждение работы генерации на опубликованном сайте (GitHub Pages).

## [1.0.0] - 2026-10-19

### Добавлено
- Начальная версия проекта
- Редактор карточек
- Галерея карточек
- Превью карточек
- Импорт/экспорт данных
- Просмотр для печати
- Настройка деплоя на GitHub Pages
